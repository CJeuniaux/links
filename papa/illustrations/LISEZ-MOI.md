# Illustrations des tuiles de l'accueil

Déposez ici une image par tuile, avec **exactement** ces noms (en .jpg, .png ou .webp) :

| Fichier | Tuile |
|---|---|
| `messages` | Messages de la famille |
| `nouvelles` | Les nouvelles du jour |
| `savant` | Le savant du jour |
| `discuter` | Discuter |
| `documentaires` | Documentaires |
| `films` | Films |

Format conseillé : paysage (environ 16:9), 1200 px de large, moins de 500 Ko.
Tant qu'une image manque, la tuile garde son ancien affichage.
